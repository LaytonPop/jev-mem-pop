## Agent skills

### Issue tracker

Issues and specs live as GitHub issues, read and written through the `deck_` tools. See `docs/agents/issue-tracker.md`.

### Triage labels

Each of the five canonical triage roles uses its own name as the label string. See `docs/agents/triage-labels.md`.

### Domain docs

multi-context — one `CONTEXT.md` per sub-project, plus a `CONTEXT-MAP.md` at the repo root pointing at them. See `docs/agents/domain.md`.
